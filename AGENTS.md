# Agent Guidance

## UI work

For any UI, visual, responsive, accessibility, or content change, read `docs/DESIGN.md` first. Read `docs/mvp/copy-and-content-guidelines.md` when adding or revising user-facing text, and `docs/mvp/ui-implementation-guide.md` when implementing product UI. These documents define the application shell, theme behavior, visual tokens, component patterns, state requirements, and copy rules. Treat them as the source of truth; propose a documented design change before deviating.
