# Security policy

Please do not report vulnerabilities in public issues. Send a private report to
the repository maintainers with the affected component, reproduction steps, and
impact. Do not include passwords, tokens, private recipe data, or personal
contact data in reports. Supported versions are the default branch and the
latest tagged release.

Administrator accounts do not receive private list or recipe access by default.
Exceptional private-content access is disabled unless the self-hosted operator
explicitly enables the policy; enabled grants are purpose-scoped, short-lived,
and recorded in a metadata-only audit trail.
